Sobre

API de conteúdo institucional utilizada pelas páginas /about/:page. A rota da API é /api/page/{page}, consultando os registros da tabela about.

GET Consultar página institucional (about)

Endpoint da API
https://cip.brapci.inf.br/api/page/{page}
Endpoint relativo
/api/page/{page}
Content-Type
application/json
Precisa de APIKEY?
Não
Autenticação
Consulta pública, sem APIKEY ou sessão de login.
Método no serviço
BrapciApiService.get(`page/${page}`)

Variáveis da API

Parâmetros de /api/page/{page}
NomeLocalTipoObrigatóriaDescriçãoExemplo
pagepathstringSimIdentificador da página. Valores usados pelo portal: brapci (Sobre a Brapci), benancib (Sobre o Benancib), brapcilivros (Brapci Livros), how_index (Como ser indexado na Brapci) e team (Equipe).brapci

Exemplo de requisição

curl "https://cip.brapci.inf.br/api/page/brapci"

curl "https://cip.brapci.inf.br/api/page/benancib"

curl "https://cip.brapci.inf.br/api/page/brapcilivros"

curl "https://cip.brapci.inf.br/api/page/how_index"

curl "https://cip.brapci.inf.br/api/page/team"

Resultado da API

Retorna diretamente um array de blocos de conteúdo, ordenados por a_order crescente. O idioma está fixado em pt no backend; não há parâmetro de idioma. Cada row pode conter HTML ou texto simples. Sem registros para a página, retorna []. O exemplo abaixo é ilustrativo.

[
  {
    "row": "<ul><li><a href=\"#apresentacao\">Apresentação</a></li></ul>",
    "lang": "pt",
    "ordem": 0
  },
  {
    "row": "<section id=\"apresentacao\"><h2>Apresentação</h2><p>Sobre a Brapci.</p></section>",
    "lang": "pt",
    "ordem": 1
  }
]

Variáveis de retorno

Campos retornados por /api/page/{page}
NomeTipoDescrição
[]array<object>Blocos da página na ordem de apresentação; array vazio quando não há conteúdo.
[].rowstringConteúdo do bloco em HTML ou texto simples.
[].langstringIdioma do bloco. Atualmente pt.
[].ordemintegerValor de a_order. Blocos com ordem 0 compõem a navegação da página; os demais compõem o conteúdo.
